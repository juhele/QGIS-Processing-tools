The scripts have built-in styles, but as an addition, I also provide separate style files for further use.

Formats:

**QML - The QGIS Style File Format**
- for details see: https://docs.qgis.org/3.44/en/docs/user_manual/appendices/qgis_file_formats.html#qml-the-qgis-style-file-format

**Styled Layer Descriptor (SLD) format**
-  XML schema specified by the Open Geospatial Consortium (OGC) for describing the appearance of map layers
-  for details see: https://www.ogc.org/standards/sld/
